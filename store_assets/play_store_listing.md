## Full description

DocForge — PDF Editor & Tools is a fast, privacy-focused utility for working with PDFs and images — entirely on your device.

**PDF Tools**
• Compress PDF — reduce file size with quality presets
• Merge PDF — combine multiple PDFs in any order
• Split PDF — extract pages or split into separate files
• Scan to PDF — camera scan with crop and enhancement
• Image to PDF — convert photos into a PDF document
• PDF to Image — export pages as JPG or PNG

**Image Tools**
• Convert format — JPG, PNG, BMP, and more
• Compress image — quality control with size preview
• Resize image — pixels, percentage, or target file size

**Batch Processing**
Process multiple files at once. Convert, compress, or resize in one run.

**Privacy First**
Core processing happens locally. Your documents are not uploaded to our servers for conversion.
